# Jamaica compatibility plan

Initial market: Jamaica only.

## Mobile operators
- Digicel Jamaica
- FLOW Jamaica

Carrier support is for optional cellular calling and device/network compatibility. SIM-free offline calling is independent of both operators.

## Device test matrix
Record manufacturer, model, Android version, security patch, Bluetooth version, Wi-Fi Direct behavior, battery optimization settings and test outcome.

Test Digicel and FLOW outgoing/incoming calls and VoLTE where provisioned; dual-SIM selection; SIM removed; mobile data disabled; Wi-Fi internet disconnected; airplane mode with local radios manually re-enabled where permitted; direct discovery, pairing, call setup, two-way audio and recovery; mesh relay consent, forwarding, route failure and battery impact.

Suggested consenting field testers: Kingston/St Andrew, Spanish Town, Portmore, Montego Bay, Ocho Rios, Mandeville, May Pen, Port Antonio and Negril. These are test locations, not coverage guarantees.

LINKA does not bypass carrier billing, SIM provisioning, VoLTE requirements, emergency-call rules or operator controls.
