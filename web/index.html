Device-key E2EE

Each browser device creates its own non-exportable ECDH P-256 key. Messages are encrypted in this browser and a separate content key is wrapped for every active conversation device. LINKA's server stores ciphertext and wrapped keys only.

Your encrypted messages will appear here.

Files are encrypted in this browser. LINKA stores only ciphertext and a separate wrapped key for each active device.

Messaging keys are registered for this browser after sign-in.

Browser encrypted text and file attachments (up to 4 MiB) are supported. Per-device delivery/read receipts are recorded. Native Android attachment picker/download remains unfinished. Every active device must register its encryption key before sending.

ABOUT THE PROJECT

LINKA is being built for Jamaica and international communication.

A Jamaica-first field-validation effort with an existing Android nearby/mesh voice foundation and a roadmap for Jamaican and international telephone numbers, carrier services and internet communication.

Important distinction

This browser companion is a separate web interface. It does not replace the Android app's radio access and it does not provide offline mesh coverage by itself.

No false coverage claims

Every live route must be measured. A radio gap cannot be crossed without a relay.

No silent carrier fallback

Offline calling must fail clearly rather than unexpectedly using chargeable cellular service.
