ABOUT THE PROJECT

LINKA is being built for Jamaica.

An Android-first communication network designed around SIM-free nearby communication and a future multi-hop offline relay system.

Important distinction

This browser companion is a separate web interface. It does not replace the Android app's radio access and it does not provide offline mesh coverage by itself.

No false coverage claims

Every live route must be measured. A radio gap cannot be crossed without a relay.

No silent carrier fallback

Offline calling must fail clearly rather than unexpectedly using chargeable cellular service.
